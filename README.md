# Jungle Dash

A responsive browser endless runner with a Three.js 3D track and obstacle scene, a canvas-rendered jungle backdrop, and a friendly bear runner.

## Run it

Install dependencies once with `npm install`, then start the development server with `npm run dev`. Open the local URL printed by Vite. Build a production version with `npm run build`.

## Features

- Responsive start, gameplay, pause, settings, and run-results screens
- Three-lane perspective track rendered in 3D
- Three-dimensional single-story jump blocks, two-story ladder and solid towers, and raised single/double underpasses
- Brown-bear runner sprite from `data/player_data/player-sprites.svg`
- Keyboard and swipe controls, jump and slide actions
- Score, distance, sound toggle, and locally saved best distance

Controls: arrow keys or A/D to change lanes, Up/Space to jump or climb a nearby ladder tower, Down to slide under raised obstacles, P/Escape to pause; on touch screens swipe in the matching direction.
