# Build order

1. Player movement and input using `player_data/` and `controls_data/`.
2. Track scene, camera, and reusable segments using `track_data/`.
3. Obstacles and hit logic using `obstacle_data/` and player collision boxes.
4. Coins, score, and power-ups using `collectible_data/` and `game_systems/`.
5. Start, pause, game-over, and restart screens using `ui_data/`.
6. Responsive touch and keyboard testing on real phone and desktop browsers.
7. Add licensed sound, visual effects, difficulty tuning, and persistence.
8. Create more original characters, environments, missions, and progression.

The modules and assets in this starter data pack are ingredients; a renderer/game engine integration and gameplay testing are still required to turn them into a complete published game.
