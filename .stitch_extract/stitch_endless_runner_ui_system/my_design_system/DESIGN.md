# Design System

## Brand & Style
The design system adopts a **Corporate / Modern** aesthetic, prioritizing clarity, efficiency, and professional reliability. The visual language is built on the **Inter** typography family, clean structural layouts, and a light color mode framework.

## Colors
- **Primary:** `#1275e2`
- **Secondary:** `#5f78a3`
- **Tertiary:** `#c55b00`
- **Neutral:** `#74777f`

## Typography
All headlines, body copy, and labels use the **Inter** font family to maintain a clean, modern, and readable interface.

## Layout & Spacing
Built with a fluid grid, consistent gutters (`1.5rem`), outer margins (`2rem`), and a proportional spacing scale to establish clear structural rhythm.

## Elevation & Depth
Relies on tonal layering and clean container separations with minimal shadows to maintain a flat, modern aesthetic.

## Shapes
Standardized around a **Rounded** theme (`2`), applying a 0.5rem default radius to interactive elements and inputs.

## Components
Includes standardized guidelines for buttons, chips, lists, inputs, cards, and selection controls.
